# ADR（Architecture Decision Records）

設計上の重要な判断を記録する。1 判断 = 1 ファイル。

- ファイル名: `NNNN-<kebab-case-title>.md`（連番）
- ステータス: `提案` → `承認` → （必要に応じて）`廃止` / `置換: NNNN`
- 承認済み ADR の内容は書き換えず、判断を変える場合は新しい ADR で置き換える
