# 要件定義（初期版）

> ステータス: ドラフト（2026-10-05）
> 本書は MVP までの範囲を定める。実装が進んで差分が出た場合は実装を優先し、本書を即時修正する。

## 1. プロダクト概要

nowwhats は、キー入力や音声入力でタスクを手軽に登録し、進捗や成果を可視化する **個人用** タスク管理アプリである。

- まず **Web アプリ** として提供する
- 将来、Windows / macOS / iOS / Android のネイティブアプリとしてリリースする

## 2. 利用者

- 個人利用のみ。1 アカウント = 1 利用者
- 同一利用者が複数端末（PC・スマートフォン）から利用する
- チーム共有・権限管理はスコープ外

## 3. 機能要件

| ID   | 機能                                         | 優先度 | 備考                                                                                               |
| ---- | -------------------------------------------- | ------ | -------------------------------------------------------------------------------------------------- |
| F-01 | テキスト入力でタスクを登録する               | MVP    | 入力の手軽さを最重視（最小入力はタイトルのみ）                                                     |
| F-02 | タスク一覧を表示する（状態・期限で絞り込み） | MVP    |                                                                                                    |
| F-03 | タスクの状態を変更する（着手・完了・中止）   | MVP    | 状態遷移は `docs/domain/glossary.md` 参照                                                          |
| F-04 | タスクの期限・優先度を編集する               | MVP    | 詳細パネルでタイトル・説明文・ポイントとあわせて編集できる                                         |
| F-05 | オフラインでタスクを登録・編集する           | MVP    | オンライン復帰時に自動同期                                                                         |
| F-06 | 複数端末間でタスクを同期する                 | MVP    |                                                                                                    |
| F-07 | 進捗・成果を可視化する（完了数の推移等）     | MVP    | 今週のまとめ（先週比・平均ベロシティ）、週ごとの完了ポイント、活動カレンダー、完了したタスクの一覧 |
| F-08 | 音声入力でタスクを登録する                   | 後続   | 文字起こし結果を F-01 と同じ経路で登録                                                             |
| F-10 | タスクにストーリーポイントを付ける           | MVP    | 既定の目盛りはフィボナッチ数列（1〜13）、未指定時は 1                                              |
| F-11 | タスクに説明文を Markdown で書く             | MVP    | 表示時に無害化（DOMPurify）する                                                                    |
| F-09 | 入力文から期限・優先度を自動抽出する         | 後続   | LLM 等を利用。オフライン時は下書き保存し、復帰後に解析                                             |

## 4. 非機能要件

| 項目                   | 要件                                                                        |
| ---------------------- | --------------------------------------------------------------------------- |
| オフライン             | 通信断でも登録・編集・閲覧ができること（ローカルファースト）                |
| マルチプラットフォーム | ドメインロジックを Web / モバイル / デスクトップ / サーバーで共有できること |
| データ保護             | 利用者は自身のデータにのみアクセスできること。通信は TLS                    |
| 拡張性                 | 入力解析（音声認識・抽出）の実装を差し替え可能であること                    |
| 運用                   | GCP（Cloud Run）上で稼働し、インフラは Terraform で管理すること             |

## 5. スコープ外（MVP 時点）

- チーム共有、タスクの割り当て
- 外部カレンダー・他タスクサービスとの連携
- 通知（リマインダー）※ 後続で検討
