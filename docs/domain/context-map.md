# コンテキストマップ

> ステータス: ドラフト（2026-10-05）

## 全体像

```
                ┌──────────────────────────┐
                │ Identity（汎用）          │
                │ 外部認証サービスを利用     │
                └────────────┬─────────────┘
                             │ OwnerId を供給（ACL 経由）
                             ▼
┌───────────────────┐  TaskDraft 確定   ┌──────────────────────────┐  ドメインイベント  ┌─────────────────────┐
│ Capture（支援）    │ ───────────────▶ │ Task Management（中核）   │ ───────────────▶ │ Insights（支援）     │
│ 入力受付・解析     │  Customer/Supplier│ Task 集約・状態遷移       │  Published Event │ 読み取りモデル・集計 │
└─────────┬─────────┘                   └──────────────────────────┘                   └─────────────────────┘
          │ TaskDraftParser（Port）
          ▼
┌───────────────────────────────┐
│ 外部: 音声認識 / LLM（ACL）     │
└───────────────────────────────┘
```

## コンテキスト一覧

| コンテキスト    | 分類 | 責務                                   | 配置                                                         |
| --------------- | ---- | -------------------------------------- | ------------------------------------------------------------ |
| Task Management | 中核 | タスクとタグのライフサイクルと不変条件 | クライアント・サーバー双方（共有パッケージ）                 |
| Capture         | 支援 | 入力の受付、原文の保存、属性抽出       | 受付はクライアント。LLM 解析はサーバー                       |
| Insights        | 支援 | 進捗・成果の集計と可視化               | クライアント（ローカル集計）を基本とし、必要に応じてサーバー |
| Identity        | 汎用 | 認証・利用者識別                       | 外部サービス（ADR 予定）                                     |

## 関係

- **Capture → Task Management**: Capture は `TaskDraft` を解析し、Task Management のユースケース（`CreateTask`）を呼び出して確定する。Task Management は Capture を知らない。
- **Task Management → Insights**: Insights は Task Management の公開 API（`TaskDto`）を読んで集計する読み取り専用のモデル（`packages/insights`）。現在はクライアントのローカル DB のタスク一覧から計算するため、オフラインでも表示できる。将来、件数が増えた場合はドメインイベントから読み取りモデルを組み立てる方式に移す。
- **外部サービス → Capture**: 音声認識・LLM は `TaskDraftParser` Port の Adapter として実装し、腐敗防止層（ACL）で外部の型をドメインに持ち込まない。
- **Identity → 各コンテキスト**: 認証サービスの利用者 ID を `OwnerId` に変換して渡す。

## 実装形態

- 初期は **モジュラーモノリス**。コンテキストごとにパッケージを分け、デプロイ単位は 1 つ。
- コンテキスト間の参照は、公開されたユースケース／イベント経由に限定し、lint で強制する。
